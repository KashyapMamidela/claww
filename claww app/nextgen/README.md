# nextgen/

Everything needed to build CLAWW Next Gen in Claude Code.

- `claww-nextgen-build-plan.md` — the specification: evaluation of the 2 Nov plan, final decisions, screen map, design system, UX rules, data model, parallel work, skills, open decisions, plan score.
- `claww-nextgen-phased-prompts.md` — the phases NG 0 to 15: standing rules and the prompt for every step, to paste into Claude Code.
- `design/index.html` — gallery of all screens (open in a browser).
- `design/screens/` — 20 screen images at 2x; the visual spec each phase must match.
- `design/html/` — the same screens as working HTML (tap through them). `support.js` renders them in a normal browser; fonts are local.

Start with section 3 of `claww-nextgen-phased-prompts.md`.
